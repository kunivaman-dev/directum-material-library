# Directum Material Library

Статический каталог иконок Directum, синхронизированный с библиотекой
[Figma](https://www.figma.com/design/nCpoXr1g7y4CP4BNBCIas8/).

## Как устроены данные

- `dist/catalog.js` — единый источник метаданных для сайта: название, категория,
  описание, поисковые ключи и варианты.
- `dist/assets/variants/<node-id>.svg` — SVG, экспортированные из Figma.
- `dist/app.js` — поиск, фильтры, выбор варианта и цвета, SVG/PNG-экспорт.
- `dist/index.html` и `dist/styles.css` — интерфейс каталога.

На сайте используются категории из поля `category:` в описании компонента Figma.
Если поле не заполнено, иконка попадает в «Без категории». Поиск намеренно не
использует старые свободные строки и автосгенерированные теги: они содержали
нерелевантные значения. Сейчас индекс строится по названию, категории и
`description:`.

Одинаковые названия не объединяются: в Figma это разные рисунки. Чтобы карточки
можно было различить, сайт добавляет к ним номера, например «Смайл · 1».

## Проверка

```bash
node test-variants.cjs
```

Тест проверяет количество карточек и вариантов, наличие и валидность всех SVG,
набор категорий, поиск по описаниям, отсутствие старого тега «ежедневник» в
индексе и безопасную перекраску одноцветных вариантов.

## Правила обновления

1. Считать из Figma владельцев иконок и поля `category:`, `keywords:`,
   `description:`.
2. Экспортировать все новые и изменённые варианты в SVG.
3. Пересобрать `catalog.js`, не добавляя в поиск свободный legacy-текст.
4. Запустить `node test-variants.cjs`.
5. Проверить каталог в браузере на desktop и mobile.
6. Только после проверок публиковать новую версию сайта.

Текущий снимок: 238 карточек, 1 183 варианта, 8 категорий с учётом
«Без категории».
